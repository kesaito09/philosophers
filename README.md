# philosopher
1. interface/ (インターフェース層)
プログラムの「顔」となる部分です。

main.c: 全体の実行フローを記述。

parser.c: 引数を数値に変換し、エラーがあれば即座に弾きます。ドメイン層に汚い文字列操作を持ち込ませないための防波堤です。

2. application/ (アプリケーション層)
「どうやって動かすか」を管理します。

initializer.c: 全哲学者のインスタンス化と、フォーク（Mutex）の配布。

simulation.c: pthread_create と pthread_join の管理。

monitor.c: 死神スレッド。全哲学者の健康状態を外側からチェックします。

3. domain/ (ドメイン層)
「哲学者が何をするか」という純粋なビジネスロジックです。

actions.c: フォークを拾う順序（ソートや偶数・奇数）をここに記述します。

ポイント: ここには printf や gettimeofday を直接書かず、インフラ層の関数を呼び出すようにすると、ロジックが非常に読みやすくなります。

4. infrastructure/ (インフラストラクチャ層)
OSやライブラリに依存する「道具箱」です。
