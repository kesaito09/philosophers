# Philosophers

## 1. Interface層 (インターフェース層)

プログラムの「顔」となる部分です。

- **main.c**: 全体の実行フローを記述
- **parser.c**: 引数を数値に変換し、エラーがあれば即座に弾く。ドメイン層に汚い文字列操作を持ち込ませないための防波堤

## 2. Application層 (アプリケーション層)

「どうやって動かすか」を管理します。

- **initializer.c**: 全哲学者のインスタンス化と、フォーク（Mutex）の配布
- **simulation.c**: `pthread_create` と `pthread_join` の管理
- **monitor.c**: 死神スレッド。全哲学者の健康状態を外側からチェック

## 3. Domain層 (ドメイン層)

「哲学者が何をするか」という純粋なビジネスロジックです。

- **actions.c**: フォークを拾う順序（ソートや偶数・奇数）をここに記述

> **ポイント**: `printf` や `gettimeofday` を直接書かず、インフラ層の関数を呼び出すようにすると、ロジックが非常に読みやすくなります。

## 4. Infrastructure層 (インフラストラクチャ層)

OSやライブラリに依存する「道具箱」です。
